# Decision to validate

Where should Stats live, and how ambitious should the first version be?

| Option | Placement | Data available now | Product cost |
| --- | --- | --- | --- |
| A | Compact snapshot on the main library | Tracks, duration, playlists | Low, but it adds height above the music list |
| B | Stats tab inside Browse | Tracks, duration, playlists, favorites, genres, metadata coverage | Low to medium, and keeps the library compact |
| C | Dedicated Listening page | None of the listening metrics yet | High, because playback history and privacy controls must be added |

Suggested starting point: **B**. It provides useful, honest information without making the main page taller or collecting new behavior data. A small piece of A could be added later if one or two headline numbers prove useful every day.
